# Bornz Studio

- Site : `public/` (GitHub Pages, branche `master`), base Supabase (`supabase/*.sql`). Voir README.md.
- Skill de conception des sites : `.claude/skills/bornz-studio-sites/`. À utiliser pour tout nouveau
  site, landing page ou démo.
- Quand l'utilisateur dit « ajoute au fichier skills » (ou « ajoute ce prompt / cette référence aux
  skills »), enrichir ce skill selon la section « Quand l'utilisateur dit « ajoute au fichier skills » »
  de son SKILL.md, committer, puis renvoyer le paquet `.skill` mis à jour.
- Ne jamais demander ni accepter la clé Supabase « service_role » / « secret ».
